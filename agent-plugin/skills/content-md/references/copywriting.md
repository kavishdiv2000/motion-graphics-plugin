# Copywriting for kinetic typography

On screen, every word costs time. A viewer reads ~4 words/second when the words arrive one at a time,
and needs ~0.8 s to absorb a landed hero. Write for the eye, not the ear.

## Rules
1. **One idea per scene.** If a scene has an "and", it's two scenes.
2. **The hero is the meaning.** Read only the heroes in order and you should get the argument:
   HOURS. → LEVERAGE. → MINUTES. → THINK. → JUDGMENT. → OWN THE VISION. → ARCHITECT.
3. **Setups are incomplete on purpose.** "You don't need more …" creates a gap that the hero closes. Let the hero finish the sentence.
4. **Concrete beats abstract.** "8 HOURS A DAY" beats "a lot of time". "MINUTES." beats "faster".
5. **Parallel grammar in stacks.** SYSTEMIZE THE ROUTINE. / DELEGATE THE EXECUTION. / OWN THE VISION. Same verb + object shape.
6. **Short words win in display faces.** Wide fonts make 9+ letter words small, so prefer the shorter synonym
   (USE beats UTILISE, FAST beats EXPEDITIOUS).
7. **Punctuation is rhythm.** A full stop on a hero makes it a verdict. No exclamation marks: confidence doesn't shout.
8. **No hedging** in heroes ("maybe", "kind of"). Hedge in the tail if honesty demands it.
9. **The CTA is a verb plus a destination**: "BOOK A CALL // site.com", "COMMENT 'MAP'", "FOLLOW FOR PART 2".
10. **Read it aloud at speed.** If you stumble, the viewer will too.

## Rewrites that fix common build errors
| Too long | Rewrite |
|---|---|
| headline "PRODUCTIVITY." (13) is fine, "TRANSFORMATION." (15) is too long | "CHANGE." / "SHIFT." / "REBUILD." |
| setup "Most people spend the majority of their working day on" (54) | "Most people spend" + line "8 HOURS A DAY" |
| line "DELEGATE ALL OF THE EXECUTION WORK." (35) | "DELEGATE THE EXECUTION." |
| stat "40,000+" (7) is fine, "$1,250,000" (10) is too long | "$1.25M" |

## Hook formulas (scene 1, ≤ 1.5 s to hero)
- You don't need more **X.** (negation → correction next)
- Stop **X-ing.**
- **N** words that **…**
- If you **[situation]**, watch this.
- **X** is dead. *(only if you can defend it)*
