# Arc library

Pick by objective. Each row is the scene roles in order. Durations assume the "steady" pace.

## Awareness (stop the scroll, plant one idea)
| Arc | Scenes | Use when |
|---|---|---|
| **Case file** (the demo) | diagnosis → correction → observation → consequence → principle → protocol → directive | a contrarian point of view, manifesto, thought leadership. 6–8 scenes, 30–40 s |
| **Myth / truth** | myth (title) → why it's wrong → truth (compare) → proof (stat) → CTA | busting a common belief. 5 scenes, 20–25 s |
| **One word** | hook word (title) → definition (sequence) → 3 implications (stack) → CTA | coining or owning a term. 4 scenes, 15–20 s |

## Engagement (comments, saves, shares)
| Arc | Scenes | Use when |
|---|---|---|
| **Listicle** | promise ("3 rules…") → rule 1 → rule 2 → rule 3 → which one? (CTA = comment) | saveable advice |
| **Hot take** | provocative claim → steel-man → counter → verdict → "agree?" | debate bait (stay honest) |
| **Before / after** | before state → pain → after state (compare) → how (list) → CTA | transformations |

## Lead generation (move to a lead magnet / DM keyword)
| Arc | Scenes | Use when |
|---|---|---|
| **Problem → mechanism → offer** | problem → cost (stat) → mechanism (stack) → what you get (list) → comment KEYWORD | lead magnets |
| **Diagnostic** | "if you…" ×3 (statement each) → the cause → free audit CTA | services |

## Conversion (click, book, buy)
| Arc | Scenes | Use when |
|---|---|---|
| **PAS** | problem → agitate → solution → proof (stat) → offer + urgency → CTA | direct response |
| **Feature → benefit → proof** | feature (title) → benefit → proof (stat) → objection handled (compare) → CTA | product ads |

## Retention (existing audience/customers)
| Arc | Scenes | Use when |
|---|---|---|
| **Changelog** | what's new (title) → 3 updates (list) → why it matters → where to find it | product updates |
| **Tip of the week** | context → tip (stack) → example → follow CTA | series content |

## Hook patterns (scene 1)
- **Negation**: "You don't need more HOURS." (the demo). Sets up a correction.
- **Number**: "3 WORDS that…", "92% of…" (needs a source).
- **Call-out**: "If you run a 10-person agency…"
- **Contrarian**: "Stop writing PROMPTS."
- **Question**: "Why can't your team THINK?" (answer it by scene 3)
- **Outcome-first**: "8 HOURS → 8 MINUTES."
